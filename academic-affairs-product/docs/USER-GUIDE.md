# 使用指南（USER GUIDE）

ZJUI 教务证据问答——每个答案可回到原文出处。**本系统仅限内网使用（未启用认证）**。

## 1. 启动

双击 `academic-affairs-product\启动教务问答.bat`。

启动器会自动：自检（缺什么会用人话告诉你缺哪类：环境/build/前端）→ 依次启动语料检索运行时、产品服务、导入看门狗 → 自动打开浏览器 `http://127.0.0.1:8770/`。

**关闭**：在启动器窗口按一次 `Ctrl+C`，三个服务全部停止。

（已在运行时再次双击 = 直接打开页面。）

## 2. 提问

- 首页可直接点示例问题；或在底部输入框输入问题，**Enter 发送**、Shift+Enter 换行（`/` 聚焦输入框，`N` 新对话）。输入框下方的「身份」（本科生/研究生）与「学期」胶囊帮助系统对准适用范围，选择会被记住。
- **左侧栏**：最上方「新对话」，下方按日期分组显示本浏览器的历史对话，点击切回；底部「控制台」进入独立的控制台空间（标签页：材料导入 / 运行状态），用左上角「返回对话」回来。侧栏底部与控制台顶栏都有：知识库在线状态、中/EN 语言切换（同时决定 LLM 回答语言）、浅色/深色主题。
- **对话流程**：进度刻度盘与步骤依次显示 01 理解问题 → 02 检索证据 → 03 生成回答 → 04 核对引用，检索完成即列出命中的文档（含来源链接）；生成期间答案**实时逐字显示**（标注「生成中」或「正在核对引用」），全部结束后显示最终状态标签与可点击的引用。可随时点停止按钮中断。
- 答案区：
  - 答案正文中的数字角标可点击，右侧弹出「引用原文」抽屉：证据原文、来源链接、文档 ID（Esc 关闭）；
  - 「逐条依据」列出每条事实及其引用的材料，点任一材料同样打开右侧抽屉（含发布方、发布日期与原文链接）；
  - 状态标签旁「引用已核对」= 每个 claim 的日期/数字/课程代码都落在所引证据内；橙色「引用待核对」= 答案照常展示但请重点核对引用（悬停可见说明）；
  - 「证据存在分歧」= 证据之间有事实分歧，双方来源都已列出，请以官方最新发布为准；
  - 灰色标签的拒答 = 当前知识库没有覆盖所问范围（学期未发布/面向其他对象/证据过时），会附带原因与建议，这是**正确行为**而不是故障；对象不符时可一键切换身份重问。
- 回答下方可复制答案、👍/👎 反馈（与该次回答的 build/决策/引用一起记录），「技术详情」展开耗时、知识库版本与请求 ID。
- **历史对话恢复**：完整回答（含引用与逐条依据）缓存在本浏览器，重开历史对话可见；换浏览器或清缓存后只剩回答文本。

## 3. 导入新材料（通知 / PDF）

左侧栏底部「控制台」→「材料导入」标签：

1. 拖放或点击选择文件（PDF/Word/Excel 附件；或网页通知 HTML，选 HTML 时自动切到「网页通知」）+ 填标题（网页通知必填、需真实来源 URL；发布日期选填）。按钮会提示还缺什么。
2. 点「导入并自动发布」。系统自动执行：入库 → 快照校验 → 增量构建 → 冲突扫描 → 发布门禁 → 原子切换（约 2-3 分钟）。
3. 右侧「导入记录」以进度条显示：已提交 → 入库校验 → 构建与门禁 → **已生效（build xxx）**，或 **失败（原因；旧知识库不受影响）**。
4. 发布成功后点左上角「返回对话」，直接提问验证命中。

**失败怎么办**：最常见是发布门禁拦截（回归题行为变化）。这是保护机制——按 `docs/OPERATIONS.md` 的「门禁拦截处置」流程审查后重发即可。

## 4. 运行状态页

控制台空间「运行状态」标签：请求与延迟指标、生成服务熔断状态、用户反馈计数、回答决策与生成方式分布；知识库版本列表可冒烟测试 / 设为当前 / 一键回滚（切换与回滚会二次确认）；失败材料队列（rejected）供人工处置。

## 常见问题

- **页面打不开**：启动器窗口是否还开着？报错信息会标注缺失类别。
- **答案说"暂无适用证据"**：确认学期写对；新材料要等状态到"已发布"。
- **导入失败 detail 里写 RELEASE GATE FAILED**：见 OPERATIONS.md。
